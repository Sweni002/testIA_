# Kit du TP — Développeur Méthodes (Futurmap)

Commencez par lire `SUJET.pdf`.

## Contenu

- `donnees/dossier_exemple/` : un dossier client d'exemple (`dossier_client/`), son `bordereau.csv`, le `referentiel.json` et le résultat attendu (`attendu.json`).
- `donnees/entrainement/` : 200 pages étiquetées pour entraîner votre classification (`etiquettes.csv`).
- `rendu_modele/` : la structure de rendu à respecter, avec des fichiers de départ (dont `IA/journal_ia.md`).
- `outils/verifier.py` : note votre rendu sur le dossier d'exemple, avec les mêmes règles que la correction.

## Vérifier votre travail

```
python outils/verifier.py rendu_modele
```

La note finale est calculée sur **un autre dossier client, non communiqué**, de même nature. Un outil réglé uniquement sur l'exemple obtiendra une note faible.

## Rendu

Compressez le dossier `rendu_modele` (renommé `NOM_Prenom`) en `NOM_Prenom.zip` et déposez-le à l'adresse indiquée dans le courriel d'envoi, avant l'échéance.
